# CV en ligne - Tristan Muller

**Voir le CV :** https://tristanmuller007.github.io/CV-Tristan-Muller/

## Contexte

L'objectif était de créer mon **CV sous forme de page web**, en HTML / CSS, et de le mettre en ligne avec **GitHub Pages** pour pouvoir le partager facilement avec un simple lien.

---

## Objectifs

- Structurer un document avec du **HTML sémantique**
- Mettre en forme une page avec une **feuille de style CSS** séparée
- Rendre la page **lisible sur ordinateur et sur mobile**
- **Publier** un site statique en ligne (GitHub Pages)

---

## Contenu du CV

- **Profil & motivation**
- **Compétences techniques** : HTML / CSS, JavaScript, Python, SQL (MySQL), réseaux & Linux
- **Langues** : anglais (langue maternelle), français, espagnol
- **Expériences professionnelles** : agriculture, fromagerie, restauration, coaching de tennis
- **Formation** : BUT Informatique, IUT Lyon 1
- **Soft skills** et **centres d'intérêt**
- **Palmarès sportif** : karaté et tennis
